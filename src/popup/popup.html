              Features

              Network

              Logging (OpenTelemetry)

              Off by default. Exports events only (connections, transfer counts, errors), never URLs, titles, cookies or notes.

              Shortcuts

              • Alt+Shift+Y opens Narada.
              • Alt+Shift+S sends the current tab to the device you used last.
              • Right-click any page or link and choose Send to device with Narada.

              Change the keys at chrome://extensions/shortcuts, or in Firefox under Add-ons → ⚙ → Manage Extension Shortcuts. Quick sends carry the tab only, never sign-in data.

              Device ID
              Connections use STUN only (Google by default), with no TURN. After the handshake, data goes directly between your devices. Relays only see encrypted, unlinkable handshake messages.
